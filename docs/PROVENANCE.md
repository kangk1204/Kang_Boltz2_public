# 결과의 출처와 해석 기준

이 저장소에는 공개 PDB 구조에서 준비한 예제 입력, 테스트셋 요약과 실행 코드가 포함됩니다.
예측 구조·HTML 리포트·MSA 캐시·모델 가중치는 실행 시 생성하거나 내려받으며 Git에 포함하지 않습니다.
예제의 출처와 실행 방법은 [시나리오 안내](../examples/scenarios/README.md)와
[테스트셋 안내](../examples/testset/README.md)를 참고하세요.

## 1. 실행 조건과 완료 마커

작업 폴더(`outputs/<name>/`)에는 다음 실행 정보가 기록됩니다.

| 파일 | 의미 |
|---|---|
| `.run_fingerprint` | 입력 YAML, 실제 MSA 내용, 실행 파라미터와 runtime의 지문 |
| `.run_params.json` | samples, seed, steps, recycles, MSA, 병렬 설정과 runtime |
| `.active_boltz_dir` | 해당 실행이 사용한 `boltz_results_*` 디렉터리 |
| `.completed` | 입력·참조·분석 설정·분석 및 리포트 구현을 포함한 완료 지문 |
| `.status` | 배치 작업의 임시 상태. 배치 종료 시 삭제 |

분석 JSON은 분석 소스 해시와 의존성 버전도 기록합니다. 이전 버전에서 생성된 결과에
실행 정보가 없으면 현재 환경으로 추정하여 채우지 않습니다. 재분석은 기존 예측을
새 조건으로 다시 예측한 것과 다릅니다. WT–변이를 비교하려면 같은 조건으로 함께 실행하세요.

## 2. 분석 JSON과 리포트 JSON

`make_report.py`는 분석 JSON을 리포트 폴더에 복사합니다. 생성 시각 같은 메타데이터가
달라질 수 있으므로 파일 해시 차이만으로 수치 차이를 판단하지 말고 실제 필드를 비교하세요.

WT–변이 Δ는 전체 모델 평균의 차이이며 대표 최고점 모델끼리의 차이가 아닙니다.
모델 수·평균·표준편차·범위를 함께 확인하세요. 예측 sample의 변동을 생물학적 반복이나
친화도 개선의 통계적 증거로 해석하지 않습니다.

## 3. MSA 캐시

`--msa cache`는 서버 URL, pairing 전략과 서열을 기준으로 캐시 키를 만들고 query 서열을
검증합니다. 최초 캐시 생성은 외부 MSA 서버에 서열을 전송합니다. 과거 버전과 키 생성
규칙이 다르면 같은 서열도 다시 내려받을 수 있습니다.

## 4. 공개 테스트셋의 서열 정책

입력 항원·나노바디는 PDB 엔티티의 SEQRES 전체 서열을 사용합니다. 구조의 관측 잔기만
이어 붙이면 내부 결측 잔기가 빠질 수 있습니다. auth chain과 label subchain도 서로
다를 수 있으므로 `ResidueSpan → Entity` 매핑으로 서열을 찾습니다.

공개 테스트셋의 7oao, 8qf4, 9ho5는 이 정책에 맞게 교정하고 재예측했습니다.
8qf4는 항원 Arc 대신 나노바디 서열을 선택했던 auth/label 매핑을 교정한 사례입니다.
서열 교정 전후 결과를 같은 입력에 대한 비교로 사용하지 않습니다.

`cohort_snapshot_2026-09-19.json`은 WT 9개와 변이 180개의 입력 해시, 결과 해시,
대표 모델, 수치와 실행 조건을 보관한 공개 예제 snapshot입니다. WT는 3 samples,
변이는 1 sample이며 변이 DockQ와 WT 대비 Δ는 없습니다. 6개 표적군은 cache,
3개는 server MSA 정책을 사용했습니다. 동일 조건의 WT–변이 비교 실험으로 해석하지 않습니다.

새 비교에는 `examples/testset/batch_matched_wt_mutants.tsv`를 사용하여 WT와 변이를
동일한 samples·seed·MSA 조건으로 함께 실행하세요. 구조 신뢰도 점수와 Δ는 Kd, kon,
koff, 결합 에너지 또는 실험적 결합 여부를 직접 측정한 값이 아닙니다.
